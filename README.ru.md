# FreeDeepseek Web

Веб-чат для собственного аккаунта DeepSeek. Общайся с моделью, управляй аккаунтами, смотри статистику и настраивай приложение в одном браузерном интерфейсе.

Проект намеренно **работает только через веб-интерфейс**. В нём больше нет OpenAI-совместимого API, Anthropic API и интеграций с OpenCode, Cursor, Claude Code, Codex и другими внешними клиентами.

## Что понадобится

- Node.js 18 или новее
- Google Chrome
- Аккаунт DeepSeek

## Запуск

```bash
git clone https://github.com/BestDay333/FreeAPI.git
cd FreeAPI
npm run auth
npm run dashboard
```

1. `npm run auth` откроет Chrome: войди в DeepSeek, чтобы создать локальную сессию аккаунта.
2. `npm run dashboard` запустит веб-приложение. Открой адрес, который появится в терминале.

## Что есть в приложении

- **Чат** — потоковые ответы, история диалогов в браузере и прикрепление изображений.
- **Аккаунты** — управление несколькими аккаунтами DeepSeek и выбор аккаунта для чата.
- **Статус и использование** — состояние аккаунтов, история запросов и статистика токенов.
- **Настройки** — оформление, язык, обновления и данные чатов.

## Только веб-интерфейс

Публичного LLM API больше нет. Приложение использует внутренние маршруты только для работы собственного веб-интерфейса. Это детали реализации, а не API для сторонних программ. Старые адреса `/v1/*` больше не поддерживаются.

## Безопасность

По умолчанию сервер слушает только `127.0.0.1`. Не выставляй его напрямую в открытый интернет. Если хочешь открывать веб-интерфейс с других устройств, используй доверенную частную сеть или правильно настроенный HTTPS reverse proxy и задай `PROXY_API_KEY`.

Это неофициальная интеграция с веб-чатом DeepSeek. DeepSeek может в любой момент изменить или ограничить его работу.
