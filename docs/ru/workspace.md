# Локальная рабочая область

Режим «Рабочая область» запускает инструменты на том же компьютере, где запущен FreeAPI. VDS не используется, если сам FreeAPI не запущен на VDS. У каждого диалога своя постоянная папка в `data/workspaces/`.

## Файловый менеджер

Нажми кнопку с иконкой файлов в панели чата. Менеджер показывает файлы только текущего диалога и позволяет открывать текстовые файлы, редактировать и сохранять их, создавать файлы и папки, переименовывать, удалять и скачивать результаты. Удаление папок возможно только когда они пустые.

Файловый менеджер использует тот же идентификатор диалога, что и режим рабочей области. Он не открывает домашнюю папку пользователя или другие каталоги компьютера.

## Установка

Для Arch Linux / CachyOS:

```bash
sudo pacman -S bubblewrap util-linux
npm run workspace:check
```

Bubblewrap создаёт отдельные Linux namespaces. Рабочая папка текущего чата подключается на запись; системные каталоги доступны только для чтения. Домашний каталог пользователя, `/mnt` и Docker socket не подключаются.

## Лимиты

- Текстовый файл для чтения или записи: до 20 МиБ.
- Скачивание публичного HTTP(S)-файла: до 500 МиБ.
- Вывод одной shell-команды: до 4 МиБ.
- Одна shell-команда: до 5 минут; общий лимит запроса Workspace по умолчанию — до 30 минут.
- До 16 действий инструментов за один проход модели.
- Ограничение адресного пространства процесса — 12 ГиБ; число процессов — 768; размер одного файла — до 1 ГиБ.

Фактическая скорость и доступная память зависят от компьютера.

## Команды и интернет

Shell-команды выполняются внутри Linux namespace. Сеть для команд по умолчанию отключена; модель должна включить её только для задач, которым нужны `npm install`, `pip install`, `git clone` и другие загрузки. Отдельный загрузчик блокирует localhost, приватные и зарезервированные адреса, а также небезопасные перенаправления.

## Проверка

```bash
npm run workspace:check
npm test
```

Проверка Bubblewrap должна завершиться сообщением `Local workspace sandbox is ready`. Если запуск namespaces запрещён настройками ядра, проверь поддержку unprivileged user namespaces.
