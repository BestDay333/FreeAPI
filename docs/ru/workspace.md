# Локальная рабочая область

Режим «Рабочая область» запускает инструменты на том же компьютере, где запущен FreeAPI. VDS не используется, если сам FreeAPI не запущен на VDS.

## Установка

Для Arch Linux / CachyOS:

```bash
sudo pacman -S bubblewrap util-linux
npm run workspace:check
```

Bubblewrap создаёт отдельные Linux namespaces. Рабочая папка текущего чата подключается на запись; системные каталоги доступны только для чтения. Домашний каталог пользователя, `/run`, `/mnt` и Docker socket не подключаются.

## Как хранятся файлы

Рабочие файлы хранятся локально в `data/workspaces/`, в отдельной папке для каждого диалога. После перезапуска FreeAPI они сохраняются. В Git они не попадают.

Готовые файлы можно получить через раздел файлов в чате. Для скачивания файлов с сайтов используется отдельный загрузчик, который блокирует localhost и приватные адреса.

## Команды и интернет

Shell-команды выполняются в Linux namespace. Доступ к сети для команд по умолчанию отключён; модель должна включить его только для задач, которым нужны `npm install`, `pip install`, `git clone` и другие загрузки. Прямой инструмент `workspace_download` отдельно скачивает публичные HTTP(S)-файлы.

Для одной команды действует ограничение по времени, CPU, числу процессов, размеру файла и объёму вывода. Команды не получают доступ к домашним файлам и другим каталогам компьютера.

## Проверка

```bash
npm run workspace:check
npm test
```

Проверка Bubblewrap должна завершиться сообщением `Local workspace sandbox is ready`. Если запуск namespaces запрещён настройками ядра, проверь поддержку unprivileged user namespaces.
