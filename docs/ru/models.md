# Модели

В веб-интерфейсе доступна DeepSeek-V4.1-Flash с двумя дополнительными режимами:

- **DeepThink** — модель сначала рассуждает, затем отвечает.
- **Поиск в интернете** — использует встроенный поиск DeepSeek, если он доступен.

Выбирай модель и режим прямо в поле ввода чата. Список вариантов загружает само приложение: публичного API моделей и API для сторонних программ нет.

Старые идентификаторы моделей — внутренняя деталь совместимости, в веб-интерфейсе они не выбираются.
