# Вход и аккаунты

Приложение хранит сессии аккаунтов DeepSeek Web локально.

## Первый аккаунт

Выполни:

```bash
npm run auth
```

Откроется Chrome для входа в DeepSeek. После авторизации сессия будет сохранена локально для веб-приложения.

## Дополнительные аккаунты

Открой **Аккаунты → Добавить аккаунт** в Dashboard. Используй браузерное расширение DeepSeek Auth Exporter, чтобы экспортировать сессию из уже авторизованной вкладки DeepSeek, а затем импортируй файл прямо в Dashboard.

Файлы аккаунтов должны оставаться приватными и не попадать в git. Приложение сохраняет их с ограниченными правами доступа.

## Параллельная работа

Один аккаунт DeepSeek Web может обслуживать только один активный чат одновременно. Если несколько диалогов используют один аккаунт, они ждут очереди. Несколько аккаунтов позволяют выполнять больше диалогов параллельно.
