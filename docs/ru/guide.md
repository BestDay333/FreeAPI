# Руководство по веб-приложению

FreeDeepseek Web предназначен для работы через собственный браузерный интерфейс. Поддерживаемого API для сторонних приложений больше нет.

## Требования

- Node.js 18+
- Google Chrome
- Аккаунт DeepSeek

## Первый запуск

```bash
npm run auth
npm run dashboard
```

Первая команда откроет Chrome для входа в DeepSeek и сохранит сессию аккаунта локально. Вторая запустит веб-приложение. Открой локальный адрес, который покажет скрипт запуска.

## Чат

Открой раздел **Чат**, чтобы начать диалог. История хранится в текущем профиле браузера. Можно создавать несколько чатов, переименовывать их, искать по истории, прикреплять изображения и останавливать генерацию.

## Аккаунты

В разделе **Аккаунты** отображаются логины DeepSeek, доступные приложению. Добавляй и удаляй аккаунты там же. В боковой панели чата можно закрепить конкретный аккаунт за диалогом или оставить автоматический выбор.

Один аккаунт DeepSeek Web обслуживает только один активный чат одновременно. Остальные запросы ждут освобождения аккаунта. Несколько аккаунтов позволяют выполнять больше задач параллельно.

## Статус и статистика

- **Статус** показывает доступность DeepSeek и готовность аккаунтов.
- **Использование** показывает статистику токенов и запросов.
- **Запросы** показывает недавние запросы и ошибки.

## Настройки

В разделе **Настройки** можно изменить тему, плотность интерфейса, язык, канал обновлений и локальные данные чатов. Если сервер запущен с `PROXY_API_KEY`, введи этот ключ в Dashboard, чтобы браузер мог обращаться к внутренним маршрутам приложения.

## Архитектура только для веба

Браузер обращается к внутренним маршрутам приложения, например `/app/chat` и `/app/models`. Они нужны только веб-интерфейсу и могут меняться без предупреждения. Прежние OpenAI, Anthropic и Responses API на `/v1/*` отключены. Настройка coding agents и генерация конфигураций для сторонних клиентов удалены.

## Безопасность

По умолчанию сервер слушает `127.0.0.1`. Оставляй этот адрес, если удалённый доступ из браузера не нужен. Для удалённого доступа используй доверенную частную сеть или HTTPS reverse proxy, задай `PROXY_API_KEY` и не оставляй сервер открытым без firewall или VPN.

## Если что-то не работает

- Запусти `npm run doctor`, чтобы проверить локальную конфигурацию.
- Если вход в DeepSeek истёк, выполни `npm run auth` ещё раз.
- Если Dashboard не соединяется с сервером, проверь вывод терминала.

## Режим «Рабочая область»

Включи **«Рабочую область»** кнопкой с иконкой терминала в панели чата. После этого ассистент получит инструменты для работы с файлами, скачивания публичных файлов, создания ZIP-архивов и запуска команд. У каждого диалога своя постоянная папка. Кнопка с иконкой файлов открывает файловый менеджер: там можно просматривать и редактировать текстовые файлы, создавать папки и файлы, переименовывать, удалять и скачивать результаты.

Команды выполняются локально внутри Bubblewrap. Для Arch Linux / CachyOS установи зависимости:

```bash
sudo pacman -S bubblewrap util-linux
npm run workspace:check
```

Только рабочая папка текущего диалога доступна на запись; домашний каталог и остальные файлы системы не подключаются. Сеть shell-команд по умолчанию выключена. Текстовые файлы ограничены 20 МиБ, загрузки — 500 МиБ, команда — 5 минут, вывод — 4 МиБ, общий срок запроса рабочей области — до 30 минут.
