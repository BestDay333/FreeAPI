# Models

The web interface currently offers DeepSeek-V4.1-Flash with two optional behaviors:

- **DeepThink** — ask the model to reason before answering.
- **Web search** — use DeepSeek's native web search when available.

Choose the model and behavior in the chat composer. The available choices are loaded by the application itself; there is no public model-list endpoint or third-party API.

Older model identifiers are internal compatibility details and are not selectable in the web interface.
