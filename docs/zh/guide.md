# 网页应用指南

FreeDeepseek Web 通过自己的浏览器界面使用，不再提供供第三方应用调用的 API。

## 环境要求

- Node.js 18+
- Google Chrome
- DeepSeek 账号

## 首次启动

```bash
npm run auth
npm run dashboard
```

第一个命令会打开 Chrome 登录 DeepSeek，并在本地保存账号会话。第二个命令启动网页应用。打开启动程序在终端中显示的本地地址。

## 聊天

打开 **聊天** 开始对话。聊天记录保存在当前浏览器配置中。你可以创建多个聊天、重命名、搜索历史、添加图片并停止生成。

## 账号

在 **账号** 页面查看应用可用的 DeepSeek 登录。你可以在这里添加或移除账号。聊天侧栏中的账号选择器可以将某个聊天固定到指定账号，也可以使用自动选择。

一个 DeepSeek 网页账号同一时间只能处理一个活跃聊天。其他聊天会等待账号空闲；多个账号可以提高并行处理能力。

## 状态与用量

- **状态** 显示 DeepSeek 连接状态和账号是否就绪。
- **用量** 显示 token 和请求统计。
- **请求** 显示最近的请求和错误。

## 设置

在 **设置** 中修改主题、界面密度、语言、更新频道和本地聊天数据。如果服务器设置了 `PROXY_API_KEY`，请在 Dashboard 中输入该密钥，以便浏览器访问应用自己的内部路由。

## 纯网页架构

浏览器通过 `/app/chat`、`/app/models` 等内部路由与应用通信。这些路由只服务于网页界面，可能随时变化。旧的 OpenAI、Anthropic 和 Responses API（`/v1/*`）已禁用。Coding agent 配置和第三方客户端配置生成功能已移除。

## 安全

服务器默认监听 `127.0.0.1`。如果不需要远程浏览器访问，请保持此设置。远程访问时，请使用可信的私有网络或 HTTPS 反向代理，设置 `PROXY_API_KEY`，并使用防火墙或 VPN 保护服务。

## 故障排查

- 运行 `npm run doctor` 检查本地配置。
- 如果 DeepSeek 登录过期，再次运行 `npm run auth`。
- 如果 Dashboard 无法连接服务器，请检查终端输出。
